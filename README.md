### Overview
A luxury digital invitation replacing paper cards. Sellable SaaS for Ghanaian weddings (GH₵300-500 per wedding).

### Core Features
1. **Envelope Intro Animation**
   - "A WEDDING CELEBRATION — Bakatel weds Juliet — TAP THE SEAL TO OPEN (B&J)"
   - Tech: CSS Keyframes, JS click handler to reveal content

2. **Save The Date Module**
   - Couple photos (Bakatell & Juliet), Date, Time, Venue: New Creation Chapel Int., Kratos-Temple, Suhum
   - LOCATION: VIEW ON GOOGLE MAPS integration

3. **Live Countdown Timer**
   - "67 days 17 hours 16 min 43 sec" — updates every second
   - Calendar view: December 2026 with 5th highlighted + Add to Calendar

4. **Guest Wishes — Data Collection**
   - Google Form embedded: Your Name + Your Wish/Blessing for the Couple
   - Data stored to: philemonosei1@gmail.com
   - View All Wishes feature

5. **Design System**
   - Colors: Dark Green #0A2E26 + Gold #D4AF37 — luxury Ghanaian wedding theme
   - Fully responsive, works offline after load

### Tech Stack
HTML, CSS, JavaScript (Countdown Logic), Google Forms API, Google Maps API, Netlify
